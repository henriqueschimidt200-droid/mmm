# Mental AI — Android

Projeto preparado para gerar um aplicativo Android com Capacitor.

No computador:
1. Instale Node.js LTS e Android Studio.
2. Execute `npm install`.
3. Execute `npx cap add android`.
4. Execute `npx cap sync android`.
5. Execute `npx cap open android`.

As chaves secretas da OpenAI e Stripe devem permanecer no servidor, nunca dentro do APK.
