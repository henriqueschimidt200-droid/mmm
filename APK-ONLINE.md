# Gerar APK sem instalar programas

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para o repositório.
3. Vá em Actions.
4. Selecione “Gerar APK do Mental AI”.
5. Clique em “Run workflow”.
6. Quando terminar, abra a execução concluída e baixe o artefato “Mental-AI-APK”.

O APK usa https://mental.ai como backend quando executado dentro do Android/Capacitor. Não coloque chaves OpenAI ou Stripe no aplicativo.
